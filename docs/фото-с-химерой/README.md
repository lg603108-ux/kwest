# Фото с химерой — карточка доработки

Короткая навигация. Полные документы — рядом, в этой папке.

**Что это.** В финале квеста участник получает своё фото с химерой: выбирает сцену, загружает
фото до груди или по пояс, ждёт около 30 секунд, скачивает кадр. Первый кадр бесплатно,
дополнительные — платно (пока кнопка «скоро»).

**Где смотреть по порядку**
1. `01-request.md` — запрос автора и уточнения по ходу.
2. `00-index.md` — цель, решения, план по этапам, риски, открытые вопросы.
3. `02-сделано-2026-11-26.md` — что реально сделано, промпт целиком, проверки, что осталось.

**Где код**
- Страница: `photo.html`, `photo.js`, `photo.css`, `photo-scenes.js`, сцены в `assets/photo/`.
- Привратник с ключом модели: папка `worker/` (Cloudflare Worker `anomaly-photo`).
- Вход в квест: на финальном экране задания 10, кнопка «Сделать фото с химерой» (открывается
  поверх квеста, состояние комнаты не теряется). Код — `task10.js`, `index.html` (`#photo-overlay`).

**Живой адрес страницы:** https://photo-chimera.pages.dev

**Важно помнить**
- Ключ модели лежит только в секрете Cloudflare, в репозитории и в странице его нет.
- Лимиты кадров сейчас выключены на время тестов: `LIMITS_ENABLED` в воркере,
  `FREE_LIMIT_ENABLED` в `photo.js`. Вернуть перед показом людям; при подключении оплаты
  суточные лимиты снять совсем.
- Модель — Seedream 5.5 edit, три референса: человек, сцена, костюм без человека.

**Что осталось**
- Живой прогон в настоящей комнате до финала.
- Догрузить сцены до 10–15 и подписать названия пар.
- Оплата второго кадра.
